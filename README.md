# 🐱 Cats & Soup - Cat Tracker Checklist

A simple and aesthetic checklist to track all the cats you’ve collected in *Cats & Soup*.

Whether you're a casual player or a full-on cat collector, this tool helps you keep track of which cats you have and which ones you still need to unlock 🐾

---

## ✨ Features

* 📋 Checklist-style tracking of cats
* 🐾 Mark collected and missing cats
* 🎨 Clean and simple UI
* 💡 Easy to customize or expand
* 🌱 Beginner-friendly project

---

## 🛠️ Built With

* HTML
* CSS
* JavaScript

---

## 🚀 How to Use

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/cats-soup-tracker.git
   ```

2. Open the project folder:

   ```bash
   cd cats-soup-tracker
   ```

3. Run the project:

   * Open `index.html` in your browser
